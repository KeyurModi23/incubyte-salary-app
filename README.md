# Incubyte Salary Management Software

This repository contains the solution for the Incubyte Software Craftsperson assessment. It is a full-stack web application designed for an HR Manager to manage and analyze salary data for an organization of 10,000 employees.

## 📚 Project Artifacts
As requested in the prompt, several artifacts have been created to outline the thinking, design decisions, and AI usage during this project:
- [Requirements Document](./requirements.md)
- [Architecture & Trade-offs](./architecture.md)
- [AI Workflow & Prompts](./AI_PROMPTS.md)

## 🛠️ Tech Stack
- **Frontend**: React (Vite), TypeScript, Tailwind CSS, Shadcn UI.
- **Backend**: Node.js, Express, TypeScript.
- **Database**: PostgreSQL (managed via Prisma ORM).
- **Testing**: Jest (Backend) & Vitest (Frontend).
